# Tourly - Travel Agency Website

A modern and responsive travel agency website built with HTML, CSS, and JavaScript. This project provides a comprehensive travel planning experience with features like destination exploration, trip countdown, daily planner, and more.

## Features

- 🗺️ Interactive destination exploration
- 📅 Trip countdown and daily planner
- 💰 Currency converter
- 🎨 Trip moodboard builder
- 📝 Packing checklist
- 🗣️ Language cheat sheet
- 🏢 Airport navigation
- 💳 Budget tracker
- 📸 Travel gallery

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Maps API
- OpenWeatherMap API

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/tourly.git
```

2. Navigate to the project directory:
```bash
cd tourly
```

3. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
```

4. Visit `http://localhost:8000` in your browser

## API Keys Required

To use all features, you'll need to add your own API keys for:
- Google Maps API
- OpenWeatherMap API

Replace `YOUR_API_KEY` in the respective files with your actual API keys.
